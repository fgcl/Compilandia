# Índice
- Porto da Partida / PHASES: Fases de um compilador (pré-requisitos: nenhum)
- Floresta Léxica / TOKENS: Tokens, lexemas e padrões (pré-requisitos: PHASES)
- Floresta Léxica / REGEX_DFA: Expressões regulares e autômatos (pré-requisitos: TOKENS)
- Floresta Léxica / NFA_TO_DFA: AFN → AFD (construção de subconjuntos) (pré-requisitos: REGEX_DFA)
- Floresta Léxica / DFA_MINIMIZATION: Minimização de AFD (tabela de pares) (pré-requisitos: REGEX_DFA)
- Floresta Léxica / LEX_FLEX: Lex/Flex: o arquivo .l (pré-requisitos: TOKENS, REGEX_DFA)
- Vale das Gramáticas / CFG_DERIVATION: Gramáticas e derivações (pré-requisitos: PHASES)
- Vale das Gramáticas / AMBIGUITY: Árvores e ambiguidade (pré-requisitos: CFG_DERIVATION)
- Ponte da Transformação / LEFT_RECURSION: Recursão à esquerda (pré-requisitos: AMBIGUITY)
- Ponte da Transformação / LEFT_FACTORING: Fatoração à esquerda (pré-requisitos: CFG_DERIVATION)
- Templo Top-Down / FIRST: Conjunto FIRST (pré-requisitos: CFG_DERIVATION)
- Templo Top-Down / FOLLOW: Conjunto FOLLOW (pré-requisitos: FIRST)
- Templo Top-Down / LL1_TABLE: Tabela LL(1) (pré-requisitos: FIRST, FOLLOW, LEFT_RECURSION, LEFT_FACTORING)
- Templo Top-Down / LL1_PARSING: Analisador preditivo (pilha) (pré-requisitos: LL1_TABLE)
- Templo Top-Down / RECURSIVE_DESCENT: Descida recursiva (pré-requisitos: LL1_PARSING)
- Templo Top-Down / ERROR_RECOVERY: Erros sintáticos e recuperação (pré-requisitos: LL1_PARSING)
- Fortaleza Bottom-Up / SHIFT_REDUCE: Empilha-reduz (shift-reduce) (pré-requisitos: CFG_DERIVATION)
- Fortaleza Bottom-Up / LR0_ITEMS: Itens LR(0), closure e goto (pré-requisitos: SHIFT_REDUCE)
- Fortaleza Bottom-Up / SLR_TABLE: Tabela SLR(1) e conflitos (pré-requisitos: LR0_ITEMS, FOLLOW)
- Fortaleza Bottom-Up / LALR: LR(1) e LALR(1) (pré-requisitos: SLR_TABLE)
- Oficina Yacc/Bison / YACC_BISON: Yacc/Bison: especificação e precedência (pré-requisitos: SHIFT_REDUCE, AMBIGUITY)
- Cidade Semântica / ATTRIBUTES_TYPES: Atributos e verificação de tipos (pré-requisitos: CFG_DERIVATION)
- Cidade Semântica / SCOPE_SYMBOLS: Escopo e tabela de símbolos (pré-requisitos: PHASES)
- Cidade Semântica / AST_BUILD: Árvore sintática abstrata (AST) com classes (pré-requisitos: CFG_DERIVATION)
- Forja do Código / TAC: Código de três endereços (pré-requisitos: ATTRIBUTES_TYPES)
- Forja do Código / OPTIMIZATION: Otimização (dobra de constantes) (pré-requisitos: TAC)
- Forja do Código / CODEGEN_MIPS: Geração de código MIPS (pré-requisitos: TAC)
- Forja do Código / RUNTIME: Ambientes de execução (registros de ativação) (pré-requisitos: SCOPE_SYMBOLS, CODEGEN_MIPS)
- Forja do Código / REG_ALLOC: Alocação de registradores (pré-requisitos: CODEGEN_MIPS)
